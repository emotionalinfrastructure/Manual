# Emotional Infrastructure — Design System

Default color system for all Emotional Infrastructure work in this repo
(frontend UI, presentations, documents, brand materials): the **Emotional
Infrastructure Signature Palette**.

| Role | Name | Hex |
|---|---|---|
| Dominant institutional color | Governance Navy | `#101C2C` |
| Secondary systems/trust color | Infrastructure Teal | `#176B73` |
| Limited signature accent | Signal Copper | `#C46A3A` |
| Preferred editorial background | Warm Ivory | `#F5F1E8` |
| Secondary text / metadata | Slate Gray | `#5E6873` |
| Primary body text | Graphite | `#20252B` |
| — | White | `#FFFFFF` |

Default visual balance: ~55% Warm Ivory/White, ~25% Governance Navy, ~12%
Infrastructure Teal, ~5% Signal Copper (used sparingly — accents, not base
colors), ~3% Slate Gray/Graphite support. Overall feel: governance-grade,
technically credible, restrained, premium — suitable for research, policy,
enterprise, and implementation contexts.

CSS custom properties for this palette live in `frontend/styles.css` (`:root`)
and are shared by every page in `frontend/`.

**Exception:** use University of Phoenix brand colors instead only for
material that is explicitly school-specific (coursework, CEITR submissions,
university presentations, academic affiliation pages). Do not use University
of Phoenix colors as the identity for Emotional Infrastructure or other
independent professional work — and don't invent/guess their exact hex
values; confirm them from an official source or ask first.
