Emotional Infrastructure Middleware

The compliance & safety layer for AI conversations.

Live demo

Every message you send is run through POST /v1/turn. The middleware scores the emotional tone, checks for crisis/abuse language and PII, and returns a moderation decision plus a system directive an upstream LLM call should be steered by.

Quickstart

curl -X POST http://localhost:8787/v1/turn \
  -H "Content-Type: application/json" \
  -d '{"session_id": "demo-123", "user_message": "Hello"}'

Run everything locally with npm run dev inside middleware-worker/ (serves this page too, at http://localhost:8787/), or deploy with npm run deploy / Cloudflare's Git integration — see the top-level README.
