# SDK Positioning Language

## Primary positioning

The Emotional Infrastructure™ Standard SDK is a TypeScript governance library for implementing consent lifecycle management, audit traceability, tolerance windows, and trust repair workflows in adaptive AI systems.

## Short description

A TypeScript SDK for consent, audit, and trust repair in AI-mediated trust environments.

## Technical description

EIS SDK provides reusable governance primitives for adaptive AI systems, including Consent Token IDs, consent state transitions, tolerance-window enforcement, append-only audit logging, trace validation, and repair workflow initiation.

## Academic description

The Emotional Infrastructure™ Standard SDK operationalizes trajectory-aware AI governance by converting consent, auditability, and trust repair into executable software primitives.

## Enterprise description

EIS SDK helps AI-enabled organizations build auditable consent and trust accountability into adaptive products before system behavior escalates into compliance, safety, or user-trust failures.

## Avoid saying

- “This solves AI governance.”
- “This is fully production-proven.”
- “This prevents manipulation.”
- “This guarantees ethical AI.”
- “Zero dependencies.”

## Say instead

- “This provides governance primitives.”
- “This is a release candidate pending public CI verification.”
- “This supports consent, audit, tolerance boundaries, and repair workflows.”
- “This creates an implementation layer for Emotional Infrastructure™.”
- “This has a minimal runtime dependency footprint, with `uuid` as the runtime dependency.”
